# Changelog

All notable changes to this project will be documented here. The package follows Semantic Versioning after its first published release.

## 0.1.0 candidate

- Initial independent Composer release candidate for `cjph96/php-core`.
- Include the immutable `ElapsedDuration` value object and `InvalidElapsedDuration` validation exception, with the documented readonly consumer-subclass contract.
- Require PHP `~8.5.0`; provide no runtime package dependencies or additional extension requirements.
- No booking entities, business permissions, persistence adapters or framework integrations are included.

The candidate maps to tag `v0.1.0` when the authorized remote release is performed. Local distribution fixture versions are test-only and are never published.
